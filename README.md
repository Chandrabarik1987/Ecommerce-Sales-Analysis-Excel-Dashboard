# 📊 Ecommerce Sales Analysis Dashboard (Excel)

An interactive Excel dashboard built using PivotTables, Slicers, Dynamic Formulas (`GETPIVOTDATA`), and advanced charts to analyze ecommerce sales performance.

## 📸 Dashboard Preview
![Dashboard Preview](dashboard_preview.png)

## 🚀 Key Insights & Features
* **KPI Cards with YoY Growth:** Tracks Total Sales, Profit, Quantity, Orders, and Profit Margin with dynamic year-over-year percentage indicators.
* **Interactive Slicers:** Filter the entire dashboard dynamically by **Year**, **Segment**, and **Region**.
* **Visualizations:** Includes Monthly Sales & Profit Combo Chart, Category-wise Waterfall Chart, Sales Share Donut Chart, US State-wise Filled Map, and Top 10 Sub-Categories Bar Chart.
